# Publisher dataset review — 2026-10-23

This inventory is not an evaluated corpus. No message bodies were imported, no spam label was automatically converted to Scam, and no model was activated. Candidates exist for English, Sinhala/Singlish and Tamil; an absent local benchmark does not mean public datasets do not exist.

| Original publisher | Provenance / license / suitability |
| --- | --- |
| [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection), Almeida/Hidalgo, DOI 10.24432/C5CC84 | Historical English spam/ham; publisher lists CC BY 4.0. Candidate for independent review. Promotion is not automatically fraud. Preserve source IDs/attribution, adjudicate labels, group duplicates, and disclose age/selection limitations. |
| [IMC 2025 Fishing for Smishing author repository](https://github.com/reportsmishing/Smishing-Dataset-IMC25) | Public reports, CC BY 4.0 in LICENSE.txt. Original [analysis.R](https://github.com/reportsmishing/Smishing-Dataset-IMC25/blob/main/code/analysis.R) excludes `scam_type == "spam"` in some analyses: do not label the whole export Scam. Review classes, redact personal information, group campaigns and obtain reviewed legitimate controls; report selection is biased. |
| [Smishtank author paper](https://arxiv.org/html/2402.18430v1), Timko/Rahman | Community reports with message/sender/URL fields and manual categories. Paper CC BY-NC-SA 4.0 does not establish dataset distribution rights. Confirm data terms separately. Positive-enriched reports alone do not establish representative negatives. |
| [Sinhala/Singlish author repository](https://github.com/vikumkodikara/sinhala-singlish-phishing-detection) and [dataset notes](https://github.com/vikumkodikara/sinhala-singlish-phishing-detection/blob/main/dataset/README.md) | Repository MIT; notes describe consented survey observations and supplementary English ham/spam. Main README distinguishes authentic observations from thousands of synthetic template variants. Confirm data redistribution consent separately from code license, redact and independently adjudicate. Generated variants cannot be representative test data; small authentic samples support pilot conclusions only. |
| [SMSDHL author preprint](https://d197for5662m48.cloudfront.net/documents/publicationstatus/239396/preprint_pdf/11fd80fd1139a6c1aac6852266046865.pdf), DOI 10.36227/techrxiv.173603655.53756505/v1 | Includes Tamil among English/Indian-language SMS. Spam/ham combines promotion, phishing and other unwanted content. Dataset download and dataset-specific license were not verified in the accessible primary paper. Obtain distribution terms and review rows before scam evaluation; reconcile paper counts against the export. |
| [OpenTextShield publisher](https://github.com/TelecomsXChangeAPi/OpenTextShield) | Multilingual spam/phishing project; code MIT; author training changelog mentions Tamil/Sinhala samples. Verify dataset-specific rights, authentic/generated origins and label provenance. Available code/model does not establish benchmark suitability; no pretrained model was activated. |

Next: obtain a license-cleared versioned export, retain checksum/attribution, review privacy and consent, and independently adjudicate English examples plus legitimate controls. Use fluent reviewers separately for Sinhala, Tamil and Singlish. Freeze grouped held-out data before inspecting detector results. See [annotation workflow](rules-evaluation.md).
